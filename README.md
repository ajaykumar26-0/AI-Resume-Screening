# AI Resume Screening & Job Recommendation System

This project uses NLP and machine learning techniques to analyze resumes and
recommend suitable job roles based on skill matching.

## Features
- Resume upload (PDF)
- Text preprocessing using NLP
- TF-IDF vectorization
- Cosine similarity-based matching
- Top job recommendations
- Skill extraction
- Streamlit UI

## Tech Stack
- Python
- Scikit-learn
- NLTK
- Streamlit

## How to Run
pip install -r requirements.txt
streamlit run app.py
